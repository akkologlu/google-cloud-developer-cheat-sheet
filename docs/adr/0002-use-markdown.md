# ADR-0002 — Use Markdown as the Primary Format

## Status

Accepted

---

## Context

Several documentation formats were considered.

---

## Decision

Markdown will be used for all documentation.

---

## Rationale

Markdown is:

- GitHub-native
- Easy to maintain
- Easy to review
- Easy to convert into websites or books
- Compatible with Obsidian and other knowledge management tools

---

## Consequences

Avoid HTML whenever possible.

Prefer standard GitHub Markdown.
