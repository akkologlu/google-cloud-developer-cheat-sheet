# ADR-0004 — Prefer Mermaid Diagrams

## Status

Accepted

---

## Context

Architecture diagrams are essential for understanding cloud systems.

External image files are difficult to maintain.

---

## Decision

Whenever possible, diagrams should be written using Mermaid.

---

## Rationale

Mermaid diagrams are:

- Version controlled
- Easy to edit
- Rendered directly by GitHub
- Text-based
- Lightweight

---

## Consequences

Architecture diagrams should be stored as Markdown.

Avoid screenshots whenever possible.
