# ADR-0003 — Explain Why Before How

## Status

Accepted

---

## Context

Many cloud learning resources immediately explain APIs and features.

This often leaves readers wondering why the service exists.

---

## Decision

Every chapter must explain the problem before introducing the solution.

---

## Example

❌ Cloud Run runs containers.

✅ Developers often want to deploy containers without managing Kubernetes.

Cloud Run solves this problem by...

---

## Consequences

Every chapter begins with:

Why does this exist?
