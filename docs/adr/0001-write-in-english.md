# ADR-0001 — Write the Handbook in English

## Status

Accepted

---

## Context

The handbook was initially planned in Turkish.

However, the goal evolved from creating personal notes into building a high-quality open-source learning resource.

---

## Decision

The handbook will be written entirely in English.

---

## Rationale

Writing in English:

- Makes the handbook accessible worldwide.
- Uses official Google Cloud terminology without translation.
- Increases discoverability on GitHub.
- Makes the project suitable for professional portfolios.
- Encourages contributions from the global community.

---

## Consequences

Examples, terminology, diagrams, and documentation should all use English.

Communication during development may still happen in Turkish.
