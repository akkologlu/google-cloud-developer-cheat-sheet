## 📖 About

This repository is a **developer-focused handbook** created while studying for the **Google Cloud Professional Cloud Developer** certification.

Unlike traditional notes or copied documentation, this handbook focuses on understanding the reasoning behind Google Cloud services.

Every chapter answers questions like:

- **Why does this service exist?**
- **What problem does it solve?**
- **How does it work internally?**
- **When should I use it?**
- **When should I NOT use it?**
- **How does it compare to similar services?**

The goal is to understand Google Cloud as a software engineer—not just pass the certification exam.

---

## 🎯 Goals

This handbook is designed to help you:

- Build a strong mental model of Google Cloud.
- Understand the architecture behind cloud services.
- Choose the right service for the right problem.
- Prepare for the Professional Cloud Developer certification.
- Use Google Cloud confidently in real-world projects.

---

## 📚 Learning Philosophy

This handbook follows one simple principle:

> **Understand first. Memorize later.**

Instead of listing features, every topic is explained through:

- The problem it solves
- Internal architecture
- Real-world examples
- Service comparisons
- Visual diagrams
- Analogies
- Certification notes
