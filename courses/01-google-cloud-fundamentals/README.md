# Course 01 — Google Cloud Fundamentals

This course introduces the core concepts of Google Cloud.

Rather than explaining individual services in isolation, it builds the mental model required to understand how Google Cloud works as a platform.

---

## Learning Outcomes

After completing this course, you should understand:

- Cloud Computing
- Managed Services
- Resource Hierarchy
- IAM
- Compute Engine
- VPC
- Cloud Storage
- Cloud SQL
- Firestore
- Bigtable
- Spanner
- Containers
- Kubernetes
- GKE
- Cloud Run
